## 📚 Descripción del Proyecto

Este repositorio contiene una colección de ejercicios de programación en Java realizados durante mi bootcamp. Los ejercicios están organizados de forma progresiva, desde conceptos básicos hasta operaciones más complejas.

## 🎯 Objetivos de Aprendizaje

- ✅ Declaración e inicialización de variables
- ✅ Entrada de datos con Scanner
- ✅ Operaciones aritméticas básicas
- ✅ Intercambio de valores (múltiples métodos)
- ✅ Programación estructurada

## 🚀 Cómo ejecutar los ejercicios

1. Clona el repositorio:
```bash
git clone [URL_DEL_REPOSITORIO]
```

2. Navega al directorio:
```bash
cd CursoJava
```

3. Compila y ejecuta cualquier ejercicio:
```bash
# Ejemplo para ejercicio básico
javac ejercicios-basicos/Ejercicio1.java
java -cp ejercicios-basicos Ejercicio1

# Ejemplo para ejercicio intermedio
javac ejercicios-intermedios/Ejercicio3.java
java -cp ejercicios-intermedios Ejercicio3

# Ejemplo para ejercicio avanzado
javac ejercicios-avanzados/Ejercicio2.java
java -cp ejercicios-avanzados Ejercicio2
```
