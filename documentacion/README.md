## 📚 Descripción del Proyecto

Este repositorio contiene una colección de ejercicios de programación en Java realizados durante mi bootcamp. Los ejercicios están organizados de forma progresiva, desde conceptos básicos hasta operaciones más complejas.

## 🎯 Objetivos de Aprendizaje

- ✅ Declaración e inicialización de variables
- ✅ Entrada de datos con Scanner
- ✅ Operaciones aritméticas básicas
- ✅ Intercambio de valores (múltiples métodos)
- ✅ Programación estructurada

## 📁 Estructura del Proyecto

### 🔢 Ejercicios Básicos
- **Ejercicio1.java** - Declaración e inicialización de variables
- **Ejercicio2.java** - Intercambio de valores con variable auxiliar
- **Ejercicio3.java** - Operaciones aritméticas básicas
- **Ejercicio4.java** - Intercambio usando operaciones XOR (en desarrollo)
- **Ejercicio5.java** - Lectura y muestra de datos del usuario
- **Ejercicio6.java** - Suma de dos números
- **Ejercicio7.java** - Expresiones aritméticas con tres números

## 🛠️ Tecnologías Utilizadas

- **Java** - Lenguaje de programación principal
- **Scanner** - Para entrada de datos desde consola
- **Eclipse/IntelliJ** - Entorno de desarrollo

## 🚀 Cómo ejecutar los ejercicios

1. Clona el repositorio:
```bash
git clone [URL_DEL_REPOSITORIO]
```

2. Navega al directorio:
```bash
cd CursoJava
```

3. Compila y ejecuta cualquier ejercicio:
```bash
javac Ejercicio1.java
java Ejercicio1
```

## 📝 Notas de Desarrollo

- Cada ejercicio incluye comentarios explicativos
- Los ejercicios están numerados secuencialmente
- Se utilizan diferentes enfoques para resolver problemas similares
- Código limpio y bien documentado

## 🎓 Conceptos Aprendidos

- **Variables**: Declaración, inicialización y tipos de datos
- **Entrada de datos**: Uso de Scanner para interacción con el usuario
- **Operadores**: Aritméticos, de asignación y lógicos
- **Métodos**: Creación y uso de funciones
- **Algoritmos**: Intercambio de valores, operaciones matemáticas
